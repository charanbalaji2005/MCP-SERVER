Connect Ubuntu MCP Server Anywhere

Ready to deploy or push to your GitHub account. Connect Claude Desktop, Cursor, Antigravity IDE, or host in Docker.

🚀

Antigravity IDE

Place this in .agents/mcp_config.json in your project root.

{
  "mcpServers": {
    "ubuntu-mcp": {
      "command": "cmd.exe",
      "args": ["/c", "d:/ubuntu-mcp-server/ubuntu-mcp-server/run_ubuntu_mcp.bat"]
    }
  }
}
🤖

Claude Desktop

Add to %APPDATA%\Claude\claude_desktop_config.json:

{
  "mcpServers": {
    "ubuntu-mcp": {
      "command": "wsl.exe",
      "args": [
        "-d", "Ubuntu", "--",
        "/home/charan_balaji/.venvs/ubuntu-mcp/bin/python3",
        "-m", "ubuntu_mcp"
      ],
      "env": {
        "MCP_WORKSPACE": "/mnt/d/ubuntu-mcp-server/ubuntu-mcp-server/workspace"
      }
    }
  }
}
⚡

Cursor / Windsurf

Settings > Features > MCP > Add New MCP Server:

Type: command
Name: ubuntu-mcp

Docker Deployment

One-command containerized execution with Web GUI and Terminal:

docker build -t ubuntu-mcp-server .
docker run -d -p 8000:8000 -p 8765:8765 \
  -v $(pwd)/workspace:/app/workspace \
  ubuntu-mcp-server
