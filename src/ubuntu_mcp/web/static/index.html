Developer Client Integrations

Configure Claude Desktop, Cursor, Antigravity IDE, or host in Docker containers seamlessly.

Antigravity IDE

Place this in .agents/mcp_config.json in your project workspace.

{
  "mcpServers": {
    "ubuntu-mcp": {
      "command": "cmd.exe",
      "args": ["/c", "d:/ubuntu-mcp-server/ubuntu-mcp-server/run_ubuntu_mcp.bat"]
    }
  }
}

Claude Desktop

Add to %APPDATA%\Claude\claude_desktop_config.json:

{
  "mcpServers": {
    "ubuntu-mcp": {
      "command": "wsl.exe",
      "args": [
        "-d", "Ubuntu", "--",
        "/home/charan_balaji/.venvs/ubuntu-mcp/bin/python3",
        "-m", "ubuntu_mcp"
      ],
      "env": {
        "MCP_WORKSPACE": "/mnt/d/ubuntu-mcp-server/ubuntu-mcp-server/workspace"
      }
    }
  }
}
